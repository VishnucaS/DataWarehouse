**This project focuses on developing a data warehouse to produce actionable insights with data engineering and analytics.

1. Designing and implementing a modern data warehouse using the Medallion Architecture, structured into Bronze, Silver, and Gold layers. 

2. Building robust ETL pipelines to extract data from source systems, transform it for quality and consistency, and load it into the warehouse. 

3. Developing optimized data models with fact and dimension tables to support efficient analytical queries.

4. Delivers SQL-driven reports and dashboards to generate meaningful insights for data-driven decision-making.
